# Weather Skill

This skill helps you get weather information for any location using wttr.in or Open-Meteo.

## When to Use

Use this skill when the user asks about:
- Current weather conditions
- Temperature forecasts
- Weather for a specific location

## Steps

1. Determine the location from the user's request
2. Call the weather tool with the location
3. Parse and present the weather information

## Notes

- This skill is for weather queries only
- Not for historical weather data or severe weather alerts
- No API key required
